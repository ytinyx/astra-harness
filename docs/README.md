## 如何读实验记录

按评测入口生成自己的报告，保留输入、源码和工具身份、预算、实际环境、逐项结果及真实执行时间。预期输出只是判据，不是已通过的证据。比较两次结果前先核对条件；不把新执行记录写成过去阶段已经完成的测试。
